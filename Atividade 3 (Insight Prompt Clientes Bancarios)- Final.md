# Atividade 3 - Final  
  
''Atue como como analista de dados e analista de experiência do cliente.  
  
Sua tarefa é analisar o Feedback dos Clientes e Operadores Bancários para identificar problemas frequentes, sugestão de melhoras e erros de segurança..  
  
Contexto: Estou trabalhando com feedbacks de clientes bancários relacionados ao aplicativo, transações no geral e suporte cliente. O resultado será usado por Supervisores e Analistas para apoiar futuras decisões, impactos gerados e controles de gasto.  
  
Dados disponíveis: A base contém forma de atendimento, datas de transações, texto do Feedback e versões do aplicativo.  
  
Instruções de análise:  
  
1. Classifique os feedbacks por tema, prioridade, horário, e impacto.  
2. Identifique os principais padrões, problemas, elogios e oportunidades.  
3. Aponte evidências nos dados fornecidos.  
4. Sugira ações práticas para os clientes e para a equipe de suporte junto a equipe de TI.   
Formato da resposta: A entrega deve conter uma tabela separada por colunas com tipos de dados corretos, recomendações em forma de lista prioritárias, um resumo com ate 10 linhas, com exemplos de problemas mais encontrados.  
  
Restrições:  
  
* Use apenas os dados fornecidos.  
* Não invente números, causas ou conclusões.  
* Não exponha dados pessoais ou sensíveis.  
* Se houver informação insuficiente, indique a limitação.  
* Use linguagem simples, explicativa, e util para a tomada de decisão’’;
